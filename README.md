# 가계부

집에서 쓰는 월별 가계부. HTML 파일 하나로 돌아간다.

## 쓰는 법

- 섹션 앞 뱃지(`＋ − ↓ ·`)를 누르면 그 섹션을 어느 구역으로 보낼지 고를 수 있다.
  - `＋` 들어온 돈 — 통장·재산 모두 늘어남
  - `−` 나간 돈 — 써서 없어진 돈
  - `↓` 모은 돈 — 통장에선 빠지고 재산은 그대로
  - `·` 참고 — 어느 계산에도 안 들어감
- 잔액 = 들어온 돈 − 나간 돈 − 모은 돈
- 금액칸에 사칙연산을 쓸 수 있다. `500000+250000*2`
- 다른 항목은 대괄호로 부른다. `[월세]*12` — 대괄호에 섹션 이름을 넣으면 그 섹션 합계.
- 항목의 `●`를 켜두면 새 달을 만들 때 금액까지 넘어간다.
- 척추 맨 오른쪽 `＋`로 다음 달을 만든다.

## 데이터

브라우저(localStorage)에만 저장된다. 기기끼리 공유되지 않는다.
`백업 내려받기`로 받은 JSON을 다른 기기에서 `백업 불러오기` 하면 옮겨진다.

iOS 사파리는 오래 안 쓴 사이트의 저장소를 지우므로 가끔 백업을 받아둘 것.

## 아이패드

사파리로 열고 공유 → 홈 화면에 추가. 전체화면으로 뜬다.
